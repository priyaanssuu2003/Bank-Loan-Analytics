# Bank Loan Analytics

An interactive web-based bank loan analytics dashboard designed to explore loan applications, borrower profiles, repayment trends, risk indicators, and overall loan portfolio performance.

## 🚀 Live Demo

🔗 **[Open Bank Loan Analytics](https://bank-loan-analytics.vercel.app/)**

## 📊 Project Overview

Bank Loan Analytics is a web-based analytics application that provides an interactive interface for exploring different aspects of loan data.

The project brings together loan analysis, borrower information, risk analysis, reports, and repayment-related insights through a collection of dedicated web pages.

The goal is to make financial and loan-related information easier to explore through an intuitive dashboard-style interface.

## ✨ Features

- 📊 Interactive loan analytics dashboard
- 💰 Loan portfolio analysis
- 👤 Borrower profile analysis
- ⚠️ Risk analysis
- 📈 Reports and performance insights
- 🧮 Loan calculation tools
- 🔐 Sign-in and sign-up interface
- 🌐 Responsive web-based interface
- 🚀 Deployed online using Vercel

## 📑 Application Pages

| Page | Description |

| `index.html` | Main dashboard / landing page |
